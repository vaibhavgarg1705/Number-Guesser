# 🎯 Number Guessing Game

A fun and interactive **Number Guessing Game** built using HTML, CSS, and JavaScript. Guess the randomly generated number between 1 and 100 within 10 attempts!

## ✨ Features

- 🎲 Random number generation between 1 and 100
- 🔢 Maximum 10 attempts to guess the correct number
- 📈 Helpful hints when your guess is too high or too low
- 📋 Track your previous guesses
- 🎯 Display remaining attempts
- 🔄 Play Again button to restart the game
- 🎨 Modern UI with gradient buttons and smooth hover effects
- ⚡ Instant feedback without reloading the page

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling, gradients, animations, and layout
- **JavaScript** – Game logic, DOM manipulation, and event handling

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/vaibhavgarg1705/Number-Guesser.git
```

### 2. Open the Project Folder

```bash
cd number-guessing-game
```

### 3. Run the Game

Open `index.html` in your web browser.

Alternatively, use the **Live Server** extension in VS Code for a better development experience.

## 🎮 How to Play

1. Enter a number between **1 and 100**.
2. Click the **Submit Guess** button.
3. Read the hint:
   - Too low — try a higher number.
   - Too high — try a lower number.
4. Guess the correct number within 10 attempts.
5. Click **Play Again** to start a new game.
